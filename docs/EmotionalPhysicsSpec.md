# Emotional Physics Specification

## 1. High-Level Purpose

This document defines the mechanics of the Emotional Physics Engine within the SynchronicityEngine. Emotions are not treated as abstract concepts but as a quantifiable, physics-like system. They function as a **real-time vibrational physics feedback channel**, providing the primary mechanism for the Physical Mind to interpret its alignment with the Higher Mind and the Blueprint.

The core function of this subsystem is to:
- Translate vibrational state into experiential feedback.
- Drive the Belief ⇔ Emotions ⇔ Reality outcomes loop.
- Modulate the permeability of the belief system to new information.
- Serve as a primary input signal for the Synchronicity and Timeline systems.

## 2. Emotional Physics Engine

### 2.1. State Variables

| Variable | Symbol | Type | Description |
| --- | --- | --- | --- |
| **Valence** | `ε_v` | Float | The pleasantness or unpleasantness of an emotional state. Range: `[-1.0, 1.0]` (Unpleasant ↔ Pleasant) |
| **Activation** | `ε_a` | Float | The intensity or energy level of an emotional state. Range: `[0.0, 1.0]` (Calm ↔ Intense) |
| **Direction** | `ε_d` | Float | The expansive or contractive nature of the emotion. Range: `[-1.0, 1.0]` (Contraction ↔ Expansion) |
| **Emotional Momentum** | `p_ε` | Vector | The tendency of the current emotional state to persist over time. A vector in the Valence/Activation space. |
| **Emotional Inertia** | `I_ε` | Float | The resistance of the emotional state to change. Higher inertia requires a greater emotional force to alter the state. |
| **Emotional Gravity Wells** | `G_ε` | Map | A set of attractor states (e.g., core traumas, foundational joys) that pull the emotional vector towards them. |
| **Emotional Resonance** | `R_ε` | Float | The degree of alignment between the current emotional state (`ε`) and the Soul's Blueprint frequency. Range: `[0.0, 1.0]` |
| **Belief Permeability** | `β_p` | Float | The degree to which the Belief System is open to modification. Inversely proportional to emotional contraction and intensity. Range: `[0.0, 1.0]` |
| **Emotional Entropy** | `S_ε` | Float | A measure of the chaotic or unpredictable nature of the emotional state. High entropy indicates internal conflict or incoherence. |

### 2.2. Mechanics & Formulas

**2.2.1. Emotional Force Equation**

An emotional "force" (`F_ε`) is generated by events and belief-triggers, acting to change the Emotional Momentum.

`F_ε = E_impact * (1 / I_ε)`

- `E_impact`: A vector representing the Valence and Activation of an incoming event or belief trigger.
- `I_ε`: The current Emotional Inertia.

The change in Emotional Momentum is then:

`Δp_ε = F_ε * Δt`

**2.2.2. Damping & Settling Curve**

In the absence of new forces, Emotional Momentum decays over time, causing the state to settle towards a baseline.

`p_ε(t+1) = p_ε(t) * e^(-λΔt)`

- `λ`: A damping constant representing the Physical Mind's natural emotional regulation capacity.

**2.2.3. Resonance Amplification**

When the emotional state is in high resonance with the Blueprint (`R_ε > threshold`), positive feedback amplifies the state's direction and activation.

`ε_a(t+1) = ε_a(t) * (1 + R_ε)`
`ε_d(t+1) = ε_d(t) * (1 + R_ε)`

**2.2.4. Ego Static & Noise**

When misaligned (low `R_ε`), the Ego generates noise that distorts the emotional signal, primarily by increasing Emotional Entropy.

`ΔS_ε = N_ego * (1 - R_ε)`

**2.2.5. Energy Conversion**

Emotional energy (`E_ε = ε_a * ||p_ε||`) can be converted into two paths:
- **Insight (`Ψ`):** If `ε_d > 0` (Expansion), energy is converted into a quantifiable "Insight Packet" that can reduce the rigidity of a related belief.
- **Repression (`Ω`):** If `ε_d < 0` (Contraction), energy is stored as potential energy in an Emotional Gravity Well, increasing its mass and pull.

**2.2.6. Emotional Snap & Timeline Jumps**

If the magnitude of the emotional vector (`||ε||`) exceeds a critical threshold (`ε_crit`), a "snap" event occurs. This represents an emotional state so powerful it forces a re-evaluation of reality, increasing the `Timeline Flexibility Coefficient (TFC)` and potentially triggering a Timeline Fork event.

`if ||ε|| > ε_crit then trigger TimelineTensionEvent`

## 3. Integration With Engine Core

| Subsystem | Integration Point |
| --- | --- |
| **Belief Engine** | `β_p` (Belief Permeability) is a direct input into the `Belief-Shift Effect Function`. High `β_p` allows for easier belief modification. Insight Packets (`Ψ`) can directly target and reduce a belief's rigidity. |
| **Vibration State** | The overall emotional state vector (`ε`) provides a weighted input to the `V_PM` (Physical Mind Vibration) calculation. `V_PM` is a function of `f(ε_v, ε_a, ε_d)`. |
| **Timeline System** | `TimelineTensionEvent` is a direct trigger for the Timeline engine to evaluate potential timeline jumps. |
| **Synchronicity Engine** | Emotional Clarity, defined as `(1 - S_ε)`, directly modulates the `Synchronicity Receptivity Index (SRI)`. Higher clarity makes synchronicities easier to perceive. |
| **Event Sourcing** | All significant emotional state transitions are logged as events to the central event store for deterministic replay. |

## 4. Determinism & Replay

- **RNG:** All probabilistic elements of emotional response (e.g., resolving high-entropy states) will be derived from the master simulation seed to ensure reproducibility.
- **Vector Recording:** Emotional transitions are not stored as final states but as the sequence of forces and state vectors (`EmotionalStateTransitioned` event). Replaying the event log perfectly reconstructs the emotional trajectory.

## 5. Observability / Debugging Views

The debug UI must provide visualizations for:

- **Emotional Waveform/Spectrum:** A real-time plot of Valence (`ε_v`) and Activation (`ε_a`) over time.
- **Momentum & Inertia Vectors:** A 2D plot showing the current `p_ε` vector, with a visual indicator for the magnitude of `I_ε`.
- **Insight/Repression Logs:** A feed of `InsightPacketGenerated` and `RepressionEventLogged` events.
- **Belief Influence Map:** A visualization showing which beliefs are exerting the most force on the current emotional state.
- **Gravity Well Map:** A topological map showing the location and mass of all Emotional Gravity Wells.

## 6. Future UI Modes

While initially text-based, the system is designed to support:
