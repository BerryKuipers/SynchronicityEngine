# Consciousness Mechanics Specification

## 1. Glossary of Terms

| Term | Definition |
| --- | --- |
| **Blueprint** | The pre-incarnational energetic signature of the Soul, defining core themes, lessons, and probable timelines. |
| **Vibration** | A measure of the energetic frequency of a consciousness layer, represented as a scalar value. |
| **Resonance** | The degree of alignment between two vibrational frequencies, typically Physical Mind and Higher Mind. |
| **Belief** | A structured data object representing a mental construct held by the Physical Mind, influencing perception and reality creation. |
| **Salience** | The degree of influence a Belief has on the Physical Mind's reality interpretation. |
| **Synchronicity** | A low-probability, high-meaning event generated by the Higher Mind to provide guidance to the Physical Mind. |
| **Ego** | A distortion field generated by the Physical Mind, introducing noise and resistance into the system. |
| **Timeline** | A sequence of events experienced by the Physical Mind. |
| **Choice Purity** | A measure of how closely a decision aligns with the Higher Mind's guidance, free from Ego distortion. |

## 2. State Model

The engine's state is a snapshot of the player's consciousness at a given time tick.

### 2.1. Vibrational State Variables

| Variable | Type | Description | Range |
| --- | --- | --- | --- |
| `V_HM` | Float | Higher Mind Vibration | `[0.0, 1.0]` |
| `V_PM` | Float | Physical Mind Vibration | `[0.0, 1.0]` |

### 2.2. Belief Map

- **Type**: `Map<BeliefID, Belief>`
- **Description**: A collection of all beliefs currently held by the Physical Mind.

### 2.3. Emotional Resonance Vector

- **Type**: `Vector[Float]`
- **Description**: A vector representing the Physical Mind's current emotional state, with components corresponding to core emotions (e.g., joy, fear, anger, sadness).

- **Variable**: `A`
- **Type**: Float
- **Description**: The overall alignment of the Physical Mind with the Higher Mind.
- **Range**: `[0.0, 1.0]`

### 2.5. Timeline Flexibility Coefficient

- **Variable**: `TFC`
- **Type**: Float
- **Description**: A measure of the Physical Mind's ability to shift between probable timelines.
- **Range**: `[0.0, 1.0]`

### 2.6. Synchronicity Receptivity Index

- **Variable**: `SRI`
- **Type**: Float
- **Description**: The Physical Mind's openness to recognizing and acting on synchronicity.
- **Range**: `[0.0, 1.0]`

### 2.7. Free-will vs. Blueprint Influence Slider

- **Variable**: `FWB`
- **Type**: Float
- **Description**: A slider determining the balance of influence between free will and the pre-defined Blueprint.
- **Range**: `[-1.0, 1.0]` (`-1.0`: full Blueprint, `1.0`: full Free-will)

## 3. Formulas & Algorithms

### 3.1. Vibration Calculation

`V_PM(t+1) = V_PM(t) + (ΔV_events * W_events) + (ΔV_beliefs * W_beliefs)`

- `ΔV_events`: Change in vibration due to recent events.
- `W_events`: Weighting factor for events.
- `ΔV_beliefs`: Change in vibration due to belief resonance.
- `W_beliefs`: Weighting factor for beliefs.

### 3.2. Alignment Calculation

`A = 1 - |V_HM - V_PM|`

- The alignment `A` is the inverse of the absolute difference between the Higher Mind and Physical Mind vibrations.

### 3.3. Belief-Shift Effect Function

`Belief.strength(t+1) = Belief.strength(t) * (1 - (E_dissonance * Belief.rigidity))`

- `E_dissonance`: Cognitive dissonance from a new experience.
- `Belief.rigidity`: The resistance of the belief to change.

### 3.4. Synchronicity Probability Curve

`P(Sync) = A * SRI * (1 - N_ego)`

- `P(Sync)`: Probability of a synchronicity event occurring.
- `N_ego`: Ego distortion noise.

### 3.5. Level-Up Threshold Equations

A level-up occurs when the alignment `A` is sustained above a certain threshold for a specific duration.

`LevelUp(Physical -> Higher) if A > 0.85 for T > 100`

- `T`: Time ticks.

### 3.6. Noise Model for Ego Distortion

`N_ego = Σ(Belief_i.emotional_charge * Belief_i.salience) / num_beliefs`

- `N_ego`: A weighted average of the emotional charge and salience of all active beliefs.

## 4. Events

| Event | Trigger | Effect |
| --- | --- | --- |
| **Synchronicity Pulse** | `P(Sync)` exceeds a random threshold. | A low-probability, high-meaning event is injected into the Physical Mind's reality stream. |
| **Belief Friction** | A new experience contradicts a core belief. | `E_dissonance` is generated, triggering the Belief-Shift function. |
| **Breakthrough** | A core belief is released or transformed. | A significant, instantaneous increase in `V_PM`. |
| **Timeline Fork** | The player makes a choice with high `Choice Purity`. | The `TFC` increases, and a new probable timeline becomes the dominant reality. |
| **Destiny-Hint Emission** | `A` is high. | Symbolic clues from the Blueprint are inserted into dreams or intuition. |

## 5. Belief Engine Mechanics

### 5.1. Belief Object Shape

```typescript
interface Belief {
  id: string;
  strength: float; // [0.0, 1.0]
  rigidity: float; // [0.0, 1.0]
  emotional_charge: float; // [-1.0, 1.0]
  origin: string; // "childhood", "trauma", "insight"
}
```

### 5.2. Conversion of Experience to Belief Modification

1. An event occurs.
2. The event is filtered through the existing Belief Map.
3. The emotional response to the event is calculated.
4. The Belief-Shift function is applied to all relevant beliefs.

### 5.3. Cognitive Dissonance Resolution Model

If `E_dissonance` is high, the Physical Mind can:
1. **Reject the experience:** No change in belief.
2. **Reframe the experience:** Minor change in belief.
3. **Accept the experience:** Major change in belief (potential for a Breakthrough event).

## 8. Simulation Scaffolding

- **Time Model**: Discrete time ticks, with the ability to switch to an event-driven model for specific scenarios.
- **Determinism**: The simulation will use a seeded random number generator to ensure replayability.
- **Replayability Hooks**: The engine will expose a "save state" and "load state" API to allow for branching and exploring different timelines.

## 9. Examples & Test Cases

- **Scenario**: Player resists synchronicity 3 times.
  - **Input**: `Response Vector` indicates resistance for 3 consecutive Synchronicity Pulse events.
  - **Result**: `SRI` decreases, `P(Sync)` decreases, `N_ego` increases. The timeline becomes more "dense" and less flexible.

- **Scenario**: Player has a Breakthrough event.
  - **Input**: A core belief with high `rigidity` and negative `emotional_charge` is released.
  - **Result**: `V_PM` increases significantly, `A` increases, `N_ego` decreases. A Timeline Fork event is likely to be triggered.
