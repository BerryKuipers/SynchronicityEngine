# Roadmap

## Milestone 1: Narrative core
- Persist player sessions and narrative history.
- Extend the engine with probabilistic resonance modifiers.
- Add CLI tooling for scenario authoring.

## Milestone 2: Cooperative layering
- Support multi-agent state negotiation within the engine.
- Synchronize cross-device sessions through WebSocket broadcasting.
- Add accessibility focused presentation modes on the frontend.

## Milestone 3: Visual expansion
- Introduce a 2D rendering layer fed by engine snapshots.
- Integrate shader-driven vibrational feedback tied to resonance metrics.
- Publish SDK documentation for third-party scenario authors.
